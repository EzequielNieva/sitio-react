# Sitio web con React — Trabajo de Presentación

Sitio de tres páginas hecho con React + Vite y React Router.

| Página | Qué muestra |
|---|---|
| **Inicio** | Personajes obtenidos de una API pública ([The Rick and Morty API](https://rickandmortyapi.com)): imagen, nombre, estado, especie, género y origen. |
| **Galería** | Fotografías cargadas desde un array de objetos local (`src/data/fotos.js`), cada uno con su imagen. |
| **Contacto** | Formulario funcional que envía el mensaje por correo (vía [FormSubmit](https://formsubmit.co)) y un mapa de Google Maps embebido al lado. |

- Repositorio: https://github.com/EzequielNieva/sitio-react
- Sitio publicado: https://EzequielNieva.github.io/sitio-react/
